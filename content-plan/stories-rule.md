# Stories rule (permanent · every day, every week)

Set by Kate on 22 Nov 2026. It applies to **every** Stories plan: weekly plans, daily improved files, and any one-off Stories.

## For every story, always state
1. **Format:** 🖼️ Image or 🎬 Video
2. **Ready-to-use prompt:**
   - 🎬 Video → a **Google Flow** prompt (follow every point in "Rules that work" in `references/flow-prompt-lessons.md`)
   - 🖼️ Image → a **Gemini** prompt (see the image rules below)
3. **Text on screen:** the exact words, plus the sticker (poll, quiz, question, countdown, link) if there is one
4. **🎬 Video only: a spare prompt.** It must be a simpler or different take on the same idea.

## Apply rules 14 and 15 to Stories too
- **Rule 14 (Flow-friendly subjects):** choose steam, light, hands, sleeves, rain, fire, objects, animals and people seen from behind. Never a story that needs an exact copy of a strange real object or building.
- **Rule 15 (two-round rule):** if a clip fails twice, use the spare. If the spare fails too, post the story as an image instead.

## Gemini image rules
- Start with `Vertical 9:16 (1080×1920) photorealistic photo`.
- Describe one subject, the light, the colour palette (warm brown tones) and the mood.
- Ask for empty space for text: `the top third is calm and uncluttered`.
- Always end with: `No text, letters, numbers, logos, watermarks or faces.` Add the words in Instagram, never in Gemini.
- Real places: keep it generic (a lane, a pub bar, a garden), never "an exact copy" of a landmark.

## Reshare stories (sharing a reel or carousel)
Still give a Gemini prompt for the **background image** behind the shared post, plus the text on screen.

## Layout in a plan
1. A quick table: day · morning · midday · evening (format + idea).
2. Then, per day, one block per story: **Format · Text on screen · Sticker · Prompt · Spare** (video only).
