# Kate · Quiet days and Hidden stories

Ce dépôt sert à planifier le compte Instagram **Kate** en quelques minutes par semaine, directement depuis ton téléphone.

## Ce qu'il contient

| Fichier | À quoi il sert |
|---|---|
| `.claude/skills/weekly-plan/` | Crée le plan de la semaine : 3 reels, 2 carrousels et 3 stories par jour |
| `.claude/skills/weekly-review/` | Analyse tes résultats et te dit quoi refaire, quoi arrêter, puis propose la semaine suivante |
| `.claude/skills/daily-review/` | Chaque matin : analyse les chiffres d'hier, améliore le post du jour et te donne ta checklist |
| `hooks/hooks-library.md` | 30 formules d'accroche réutilisables |
| `references/flow-prompt-lessons.md` | Carnet Google Flow : règles qui marchent + journal des prompts |
| `tracking/results.csv` | Tes chiffres, post par post |
| `content-plan/` | Les plans de chaque semaine |
| `reviews/` | Les bilans de chaque semaine |

## Utilisation depuis ton téléphone (Android)

1. Ouvre l'app **Claude**, va dans **Code**, puis choisis le dépôt **Kate-neo**.
2. **Le dimanche**, entre tes chiffres. Pour chaque post, ouvre les statistiques dans Instagram (bouton « Voir les statistiques »), puis écris à Claude par exemple :
   > Ajoute mes résultats : reel du 24/11, 310 vues, 8 enregistrements, 3 partages, 2 commentaires, 4 nouveaux abonnés.
3. Tape **`/weekly-review`** : Claude te dit ce qui a marché, ce qu'il faut refaire et ce qu'il faut arrêter, puis il prépare la semaine suivante.
4. Pas encore de chiffres ? Tape simplement **`/weekly-plan`**.
5. Demande enfin à Claude : **« Commit, push et ouvre une pull request, puis merge-la »**. Le plan est alors enregistré sur GitHub.

Tu peux lire le plan dans l'app GitHub, dans le dossier `content-plan/`.

## Astuces
- Pour inventer une accroche toi-même, pioche dans `hooks/hooks-library.md`.
- Filme tout en **1 ou 2 sorties** : le plan regroupe les plans à tourner par lieu.
- Les posts avec un lien affilié doivent commencer par **#ad** (règle britannique).
- Les plans sont en anglais, comme ton audience (Royaume-Uni et Europe).
